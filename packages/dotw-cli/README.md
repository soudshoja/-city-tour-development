# dotw-cli

Standalone DOTW hotel booking CLI for the Akeed AI agent.

## Installation

```bash
cd packages/dotw-cli
composer install
chmod +x bin/dotw
```

## Configuration

On first run, `~/.dotw-cli/config.yaml` is created with a starter template.
Edit it with your DOTW credentials before running any commands.
