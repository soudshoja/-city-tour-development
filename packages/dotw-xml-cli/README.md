# dotw-xml-cli

Low-level DOTW XML pass-through CLI. One command per DOTW API method. Fully stateless.

## Install

```bash
cd packages/dotw-xml-cli
composer install
chmod +x bin/dotw-xml
```

## Configure

```bash
# On first run, config is written to:
~/.dotw-xml-cli/config.yaml

# Edit with your credentials before use.
```

## Usage

```bash
bin/dotw-xml <command> [options]
```

Full command reference in plan 29-03.
